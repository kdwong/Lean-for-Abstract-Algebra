Lean Proof Explanation

Line-by-line analysis of permutation swap lemmas

1 Lemma: move_swap_left

Strategy: Case analysis to move a swap to the left of a product

Overview

This lemma shows that given a swap σ and swap(a,b), their product can either cancel to identity, or be rewritten as swap(a,z) * τ where τ fixes a. This is crucial for manipulating products of swaps.

rcases hσ with ⟨x, y, hxy, rfl⟩
Strategy: Destructure the swap hypothesis
Explanation: Since σ.IsSwap, we know σ = swap(x,y) for some x≠y. We extract x, y, the proof x≠y (hxy), and substitute σ with swap(x,y) (rfl).
by_cases h : swap x y = swap a b
Strategy: Case split on equality
Explanation: First check if σ is exactly the swap we're multiplying with. This is the cancellation case.
· left; rw [h, Equiv.swap_mul_self]
Strategy: Prove cancellation
Explanation: If σ = swap(a,b), then σ * swap(a,b) = swap(a,b) * swap(a,b) = 1. Choose the left disjunct (cancellation case) and apply the theorem that a swap composed with itself is identity.
· right
Strategy: Handle non-cancellation cases
Explanation: If σ ≠ swap(a,b), we need to prove the right disjunct: find z and τ such that σ * swap(a,b) = swap(a,z) * τ with τ fixing a.
if ha : x = a ∨ y = a then
Strategy: Case analysis on whether σ involves 'a'
Explanation: If swap(x,y) involves element 'a', we can directly rewrite it as swap(a,z) for some z.
obtain ⟨z, hza, heq⟩ : ∃ z, z ≠ a ∧ swap x y = swap a z := by cases ha with | inl hxa => subst hxa; exact ⟨y, hxy.symm, rfl⟩ | inr hya => subst hya; exact ⟨x, hxy, Equiv.swap_comm ..⟩
Strategy: Normalize the swap to have 'a' as first element
Explanation: If x=a, then swap(x,y) = swap(a,y), so z=y. If y=a, then swap(x,y) = swap(y,x) = swap(a,x), so z=x. We use swap commutativity.
rw [heq]
Strategy: Substitute
Explanation: Replace swap(x,y) with swap(a,z) in the goal.
have hzb : z ≠ b := by intro hb; subst hb; apply h; rw [heq]
Strategy: Prove z≠b by contradiction
Explanation: If z=b, then swap(x,y) = swap(a,b), contradicting our assumption h that they're different.
refine ⟨b, hab.symm, swap b z, ⟨b, z, by aesop, rfl⟩, ?_, ?_⟩
Strategy: Construct the witness structure
Explanation: We provide the existential witnesses: z=b (satisfying z≠a via hab.symm), τ=swap(b,z) (proven to be a swap via ⟨b, z, proof of b≠z, rfl⟩). Two sub-goals remain: prove τ(a)=a and the main equality.
· simp [swap_apply_def]; aesop
Strategy: Prove τ(a) = a
Explanation: Simplify swap(b,z)(a) using the definition of swap application. Since a≠b and a≠z (from our case analysis), swap(b,z) leaves a unchanged. Automation (aesop) finishes.
· rw [swap_mul_swap_share_left hzb hza]
Strategy: Apply swap multiplication identity
Explanation: Use the algebraic identity: swap(a,z) * swap(a,b) = swap(a,b) * swap(b,z). This proves the required equality σ * swap(a,b) = swap(a,z) * τ.
else if hb : x = b ∨ y = b then
Strategy: Case where σ involves 'b' but not 'a'
Explanation: Similar to the 'a' case but now we normalize to swap(b,z). The algebra is slightly different but follows the same pattern.
obtain ⟨z, hzb, heq⟩ : ∃ z, z ≠ b ∧ swap x y = swap b z := by cases hb with | inl hxb => subst hxb; exact ⟨y, hxy.symm, rfl⟩ | inr hyb => subst hyb; exact ⟨x, hxy, Equiv.swap_comm ..⟩
Strategy: Normalize to swap(b,z)
Explanation: Same technique as before, but with 'b' instead of 'a'. Extract z such that swap(x,y) = swap(b,z).
rw [heq]
Strategy: Substitute
Explanation: Replace swap(x,y) with swap(b,z) in the goal.
have hza : z ≠ a := by intro Hz; subst Hz; cases hb <;> grind
Strategy: Prove z≠a
Explanation: If z=a, we'd have swap(x,y) involving 'a', contradicting that σ doesn't involve 'a' (from earlier negation of ha).
refine ⟨z, hza, swap z b, ⟨z, b, hzb, rfl⟩, ?_, ?_⟩
Strategy: Construct witness for 'b' case
Explanation: Provide witnesses: z (satisfying z≠a), τ=swap(z,b) (proven to be a swap). Two sub-goals remain.
· simp [swap_apply_def]; aesop
Strategy: Prove τ(a) = a
Explanation: Show swap(z,b)(a) = a by case analysis. Since a≠z and a≠b, the swap leaves a fixed.
· rw [swap_mul_swap_share_right hza hzb hab]
Strategy: Apply different swap identity
Explanation: Use the identity swap(b,z) * swap(a,b) = swap(a,z) * swap(z,b). This is the version for swaps sharing the right element.
else push_neg at ha hb
Strategy: Handle disjoint case
Explanation: If σ involves neither 'a' nor 'b', convert the negated disjunctions into explicit inequalities: x≠a, y≠a, x≠b, y≠b.
have hdisj : Disjoint ({a, b} : Set α) {x, y} := by rw [Set.disjoint_insert_left, Set.disjoint_singleton_left] aesop
Strategy: Prove disjointness formally
Explanation: Show {a,b} ∩ {x,y} = ∅ using set theory lemmas. This follows from x,y being different from both a and b.
refine ⟨b, hab.symm, swap x y, ⟨x, y, hxy, rfl⟩, ?_, ?_⟩
Strategy: Construct witness for disjoint case
Explanation: Use z=b and τ=swap(x,y) (which is just σ itself). Since σ is disjoint from {a,b}, it automatically fixes a.
· simp [swap_apply_def]; aesop
Strategy: Prove τ(a) = a
Explanation: Since swap(x,y) is disjoint from {a,b}, it fixes a.
· rw [swap_mul_swap_comm_of_disjoint hdisj]
Strategy: Apply commutativity of disjoint swaps
Explanation: Disjoint swaps commute: swap(x,y) * swap(a,b) = swap(a,b) * swap(x,y). This gives us the required form.

2 Lemma: exists_reduction

Strategy: Induction on list of swaps to reduce or move a final swap

Overview

Given a list M of swaps and a swap (a,b), this lemma shows that M·(a,b) can either be reduced (by canceling two swaps) or rewritten as (a,z)·M' where M' fixes 'a'. This is the key step for proving that permutations can be written as products of swaps with special structure.

induction M using List.reverseRecOn generalizing a b
Strategy: Reverse induction on the list
Explanation: We induct on M from right to left (reverse recursion). This lets us interact the rightmost swap of M with swap(a,b). We generalize over a,b since they change in the recursive call.
case nil => right
Strategy: Base case when M is empty
Explanation: If M=[], choose the "move" disjunct (right).
refine ⟨b, hab.symm, [], by simp, by simp⟩
Strategy: Provide trivial witnesses
Explanation: M·swap(a,b) = swap(a,b) = swap(a,b)·1. Use z=b and M'=[] (empty list). The empty list trivially consists of swaps fixing a, and the product is correct.
case append_singleton L s ih =>
Strategy: Inductive case M = L ++ [s]
Explanation: By reverse induction, M splits as L ++ [s] where s is the last swap. We have induction hypothesis 'ih' for L.
have hs : s.IsSwap := by simp_all
Strategy: Extract that s is a swap
Explanation: From h_swaps (all elements of M are swaps), derive that s is a swap.
have hL_swaps : ∀ x ∈ L, x.IsSwap := by simp_all
Strategy: Extract that all elements of L are swaps
Explanation: Similarly, derive that all elements of L are swaps.
rcases move_swap_left hab s hs with h_cancel | ⟨z, hza, τ, hτ_swap, hτ_fix, h_comm⟩
Strategy: Apply the first lemma
Explanation: Use move_swap_left on s and swap(a,b). This gives two cases: either they cancel (h_cancel: s*swap(a,b)=1), or we get s·swap(a,b) = swap(a,z)·τ with τ(a)=a.
· left
Strategy: Cancellation case - choose reduction
Explanation: If s·swap(a,b)=1, we have a reduction.
refine ⟨L, by simp, hL_swaps, ?_⟩
Strategy: Construct reduced list
Explanation: The reduced list is M'=L. Check: |L| + 2 = |L++[s]| + 1 = |M| + 1 ✓. All elements are swaps (hL_swaps). One sub-goal remains: prove the products are equal.
simp [List.prod_append, h_cancel]
Strategy: Prove product equality
Explanation: (L++[s]++[swap(a,b)]).prod = L.prod · s · swap(a,b) = L.prod · 1 = L.prod. Simplification with the cancellation fact completes the proof.
· specialize ih a z hza.symm hL_swaps
Strategy: Apply induction hypothesis
Explanation: We have s·swap(a,b) = swap(a,z)·τ. So (L++[s])·swap(a,b) = L·swap(a,z)·τ. Apply IH to L and swap(a,z) (note: z≠a from hza.symm).
rcases ih with ⟨L', hlen, hops', hprod⟩ | ⟨w, hwa, L', hops', hprod⟩
Strategy: Case split on IH result
Explanation: The IH gives two subcases: either L·swap(a,z) reduces to L' (shorter list), or it moves to swap(a,w)·L' with L' fixing a.
· left
Strategy: Subcase 2a - reduction propagates
Explanation: If L·swap(a,z) reduces, we get a reduction for the whole expression.
refine ⟨L' ++ [τ], ?_, ?_, ?_⟩
Strategy: Construct reduced list
Explanation: The reduced list is L'++[τ]. Three sub-goals: length, all swaps, product equality.
· simp [List.length_append]; omega
Strategy: Verify length
Explanation: |L'++[τ]| + 2 = |L'| + 1 + 2 = (|L|-2) + 1 + 2 = |L| + 1 = |M| + 1 ✓. Arithmetic solver (omega) handles this.
· intro x hx rw [List.mem_append, List.mem_singleton] at hx
Strategy: Prove all elements are swaps
Explanation: Take arbitrary x in L'++[τ]. Either x∈L' or x=τ.
rcases hx with hx | rfl · exact hops' x hx · exact hτ_swap
Strategy: Handle both cases
Explanation: If x∈L', it's a swap by IH (hops'). If x=τ, it's a swap by construction (hτ_swap).
· simp [List.prod_append, h_comm, mul_assoc, hprod]
Strategy: Prove product equality
Explanation: (L'++[τ]).prod = L'.prod · τ = L'.prod · τ (by IH: L'.prod = L·swap(a,z)) = L·swap(a,z)·τ (by h_comm: = L·s·swap(a,b)) = (M++[swap(a,b)]).prod ✓
· right
Strategy: Subcase 2b - move propagates
Explanation: If L·swap(a,z) moves to swap(a,w)·L', propagate the move.
refine ⟨w, hwa, L' ++ [τ], ?_, ?_⟩
Strategy: Construct moved form
Explanation: Use witness w (from IH, w≠a) and list L'++[τ]. Two sub-goals: all elements are swaps fixing a, and product equality.
· intro x hx rw [List.mem_append, List.mem_singleton] at hx
Strategy: Prove all elements fix a
Explanation: Take arbitrary x in L'++[τ]. Either x∈L' or x=τ.
rcases hx with hx | rfl · exact hops' x hx · exact ⟨hτ_swap, hτ_fix⟩
Strategy: Handle both cases
Explanation: If x∈L', it's a swap fixing a by IH. If x=τ, it's a swap fixing a by construction (hτ_fix).
· simp only [List.prod_append, List.prod_singleton] at hprod ⊢
Strategy: Simplify products
Explanation: Expand list products into multiplications in both the IH (hprod) and the goal.
rw [mul_assoc, h_comm, ← mul_assoc, hprod, mul_assoc]
Strategy: Algebraic manipulation
Explanation: Chain of equalities: (M++[swap(a,b)]).prod = L·s·swap(a,b) = L·(swap(a,z)·τ) (by h_comm) = (L·swap(a,z))·τ (reassociate) = (swap(a,w)·L'.prod)·τ (by hprod) = swap(a,w)·(L'.prod·τ) = swap(a,w)·(L'++[τ]).prod ✓

Proof Summary

The proof works by reverse induction on the list M:

  • Base case (M=∅): Trivially a "move" case with empty list
  • Inductive step (M=L++[s]): Use move_swap_left to interact s with swap(a,b):
    • If they cancel: Reduction directly to L
    • If they transform: Get s·swap(a,b) = swap(a,z)·τ, then:
      • Apply IH to L·swap(a,z)
      • If IH gives reduction: append τ to get reduced list
      • If IH gives move: append τ to get moved list

The key insight is that move_swap_left always makes progress: either immediate cancellation, or transformation to a form where we can recurse on a structurally simpler problem.

Key Proof Strategies

1. Case Analysis

Both proofs heavily use case splitting (by_cases, if-then-else, rcases) to handle different structural situations. This breaks complex problems into manageable pieces.

2. Algebraic Identities

Key swap identities (cancellation, commutativity for disjoint swaps, transformation rules) are applied strategically to simplify products.

3. Induction Pattern

Reverse induction on lists allows processing from right to left, perfect for interacting the last element with a new swap.

4. Witness Construction

When proving existential statements, carefully construct witnesses (z, τ, M') and verify all required properties using refine and multiple sub-goals.
