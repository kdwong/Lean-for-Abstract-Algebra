Lean Proof Explanation

Why identity permutations need an even number of transpositions

★ Theorem: even_number_of_swaps_of_identity

Strategy: Strong induction on length + contradiction via reduction lemma

Overview

This theorem proves that if a list L of transpositions multiplies to the identity permutation, then the length of L must be even. The proof uses strong induction on the list length and the reduction lemma to show that any such list can be shortened by 2, eventually reaching the base case.

generalize hn : L.length = n
Strategy: Introduce a name for the length
Explanation: We name the length of L as 'n' and keep the equality hypothesis 'hn: L.length = n'. This allows us to do induction on n while still referring back to L.
induction n using Nat.strong_induction_on generalizing L with | h n ih =>
Strategy: Strong induction on the natural number n
Explanation: Strong induction gives us the hypothesis 'ih': for all k < n, any list of length k satisfying our conditions has even length. We generalize over L because different lists might have the same length n.
subst hn
Strategy: Substitute n with L.length
Explanation: Since hn says n = L.length, replace all occurrences of n with L.length. This cleans up the context.
induction L using List.reverseRecOn with
Strategy: Reverse induction on the list L
Explanation: We induct on L from right to left. This is perfect because we'll extract the last transposition and work with M ++ [swap a b] form, matching the reduction lemma's structure.
| nil => simp
Strategy: Base case – empty list
Explanation: If L = [], then L.length = 0, which is trivially even (0 = 2·0). The simp tactic handles this immediately since the empty list's product is 1 by definition.
| append_singleton M s _ =>
Strategy: Inductive case L = M ++ [s]
Explanation: By reverse induction, L splits as M ++ [s] where s is the last element. The underscore ignores the internal IH from List.reverseRecOn (we'll use the strong IH instead).
have hs : s.IsSwap := hL s (by simp)
Strategy: Extract that s is a swap
Explanation: From the hypothesis hL (all elements of L are swaps), derive that s is a swap. The 'by simp' proves s ∈ M ++ [s], which is obvious.
rcases hs with ⟨a, b, hab, rfl⟩
Strategy: Destructure the swap
Explanation: Since s is a swap, extract elements a, b such that s = swap(a,b) with a ≠ b (hab). The 'rfl' substitutes s with swap(a,b) everywhere.
have hM_swaps : ∀ x ∈ M, x.IsSwap := fun x hx => hL x (by simp [hx])
Strategy: Prove all elements of M are swaps
Explanation: For any x ∈ M, we know x ∈ M ++ [swap(a,b)] = L, so x is a swap by hL. This prepares us to apply the reduction lemma.
rcases exists_reduction M a b hab hM_swaps with ⟨M', hlen, hM'_swaps, h_equiv⟩ | ⟨z, hza, M', hM'_fix, h_equiv⟩
Strategy: Apply the reduction lemma
Explanation: This is the key step! Apply exists_reduction to M and swap(a,b). This gives two cases:
  • Left: M·swap(a,b) reduces to a shorter list M' (length decreases by 2)
  • Right: M·swap(a,b) = swap(a,z)·M' where M' fixes a
· rw [← h_equiv] at hprod
Strategy: Case 1 (Reduction) – Rewrite the product equation
Explanation: We have h_equiv: M'.prod = (M ++ [swap(a,b)]).prod. Since hprod says (M ++ [swap(a,b)]).prod = 1, rewriting gives M'.prod = 1.
have h_lt : M'.length < (M ++ [swap a b]).length := by simp only [List.length_append, List.length_singleton] at hlen ⊢ omega
Strategy: Prove the length strictly decreased
Explanation: From hlen: M'.length + 2 = (M ++ [swap(a,b)]).length, derive M'.length < (M ++ [swap(a,b)]).length. This is straightforward arithmetic (omega handles it).
specialize ih M'.length h_lt M' hM'_swaps hprod rfl
Strategy: Apply the strong induction hypothesis
Explanation: Since M'.length < L.length (via h_lt), we can apply the strong IH. We provide:
  • M'.length (the smaller number)
  • h_lt (proof it's smaller)
  • M' (the list)
  • hM'_swaps (all elements are swaps)
  • hprod (now: M'.prod = 1)
  • rfl (proof that M'.length = M'.length)
This gives us: Even M'.length.
simp only [List.length_append, List.length_singleton] rw [← hlen] grind
Strategy: Conclude Even L.length
Explanation: We need to prove Even (M ++ [swap(a,b)]).length.
  • Simplify: (M ++ [swap(a,b)]).length = M.length + 1
  • From hlen: M'.length + 2 = M.length + 1
  • Rewrite: Even (M'.length + 2)
  • Since Even M'.length (from IH) and Even (k + 2) ↔ Even k, we're done
  • The grind tactic handles this arithmetic reasoning
· rw [h_equiv] at hprod
Strategy: Case 2 (Move) – Derive a contradiction
Explanation: We have h_equiv: (M ++ [swap(a,b)]).prod = swap(a,z)·M'.prod. Combined with hprod: (M ++ [swap(a,b)]).prod = 1, this gives: swap(a,z)·M'.prod = 1.
have h_apply : (1 : Perm α) a = (swap a z * M'.prod) a := by rw [hprod]
Strategy: Apply both sides to element 'a'
Explanation: Since the permutations are equal, applying them to 'a' gives equal results. We have: 1(a) = (swap(a,z)·M'.prod)(a), which simplifies to: a = swap(a,z)(M'.prod(a)).
simp only [Equiv.Perm.coe_one, id_eq, Equiv.Perm.mul_apply] at h_apply
Strategy: Simplify the application
Explanation: Simplify 1(a) to just 'a', and expand the multiplication of permutations. Now h_apply reads: a = swap(a,z)(M'.prod(a)).
have h_fix : M'.prod a = a := by have helper : ∀ (lst : List (Perm α)), (∀ x ∈ lst, x a = a) → lst.prod a = a := by intro lst h induction lst with | nil => simp | cons x xs ih_xs => simp only [List.prod_cons, mul_apply] rw [ih_xs (fun y hy => h y (by simp [hy]))] exact h x (by simp) exact helper M' (fun x hx => (hM'_fix x hx).2)
Strategy: Prove M'.prod fixes 'a'
Explanation: This is a mini-lemma. We prove that if every element of a list fixes 'a', then the product also fixes 'a'.
  • Base case (nil): Empty product is identity, which fixes everything
  • Inductive case (x :: xs): (x·xs.prod)(a) = x(xs.prod(a)) = x(a) (by IH) = a (by hypothesis)
We apply this helper to M', using hM'_fix which says every element of M' fixes a.
rw [h_fix, swap_apply_left] at h_apply
Strategy: Simplify using the fixed point
Explanation: Substitute M'.prod(a) = a into h_apply:
  • Before: a = swap(a,z)(M'.prod(a))
  • After substitution: a = swap(a,z)(a)
  • By swap_apply_left: swap(a,z)(a) = z
  • So: a = z
exact (hza h_apply.symm).elim
Strategy: Derive the final contradiction
Explanation: We've proven a = z (from h_apply). But hza says z ≠ a! This is a contradiction. Specifically:
  • h_apply.symm: z = a
  • hza (z = a): False (applying the inequality to the equality)
  • .elim: from False, prove anything (including the goal)
This contradiction shows Case 2 is impossible—we can't have the "move" case when the product is identity.

Proof Structure Summary

The proof works through a clever combination of strong induction and case analysis:

  • Setup: Strong induction on list length, with reverse induction on list structure
  • Base case: Empty list has length 0, which is even ✓
  • Inductive step: For L = M ++ [swap(a,b)] with L.prod = 1, apply exists_reduction:
    • Case 1 (Reduction): Get shorter list M' with M'.prod = 1
      • Apply strong IH: Even M'.length
      • Since L.length = M'.length + 2, conclude Even L.length ✓
    • Case 2 (Move): Get L.prod = swap(a,z)·M'.prod with M' fixing a
      • Since L.prod = 1, we have swap(a,z)·M'.prod = 1
      • Apply to 'a': a = swap(a,z)(M'.prod(a))
      • Since M' fixes a: a = swap(a,z)(a) = z
      • But z ≠ a by construction → Contradiction! ✗

Key insight: The "move" case is impossible when the product is identity, because moving a swap to the front would create swap(a,z) as a factor of the identity, but then applying both sides to 'a' reveals that z must equal a, contradicting the construction. So we always get reduction, which decreases length by 2, preserving parity until we reach the base case.

Proof Techniques Used

1. Strong Induction

Uses strong induction on length to handle lists that decrease by 2 (not just 1). The IH can be applied to any strictly smaller list, not just immediate predecessor.

2. Reduction via Lemma

Leverages the exists_reduction lemma to systematically reduce the problem. This modular approach breaks the proof into manageable, reusable components.

3. Proof by Contradiction

The "move" case is eliminated via contradiction: if the product is identity, you can't move a swap to the front without violating the constraint that z ≠ a.

4. Mini-Lemma (Helper)

Proves that if every permutation in a list fixes a point, their product also fixes that point. This is done inline via a simple structural induction—clean and self-contained.

Mathematical Significance

This theorem is fundamental in permutation group theory. It shows that the parity of a permutation (even vs. odd) is well-defined: you can't write the identity using an odd number of transpositions. Combined with the other direction (any even-length list of swaps gives an even permutation), this establishes that the sign homomorphism sgn: Sₙ → {±1} is well-defined and that the alternating group Aₙ (even permutations) is indeed a proper subgroup of index 2.
